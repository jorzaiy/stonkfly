# Stonkfly 模型范围与停止条件审查（2026-10-08）

状态：**正式范围决策。当前端到端“视觉输入 → MaleCNS 传播 → KC/MBON → 固定交易解码”路线停止继续稳定化。R1-A/B/C 不再推进，集成式 S3 继续阻塞。**

本审查不删除代码或产物，不否定完整图导入、确定性仿真和局部塑性代码本身；它限定这些组件目前能支持的声明，并规定什么条件下才允许重新开启端到端路线。

## 1. 决策摘要

### 1.1 立即停止

- 停止继续扫描或调整感光输入、`lamina_bias`、half-saturation、KC adaptation、APL 倍率/时序、阈值、rest 或统一权重缩放，以期在现有动力学上得到“合适”的 KC 分布。
- 停止把 S2–R0c 的同一批刺激、seed、60 帧 holdout 或历史市场 replay 用作新的调参数据。
- 不启动集成式 S3，不把当前视觉链路接入新的塑性训练、纸面交易表现比较或任何真实交易链路。
- 不再把 `20261004T-balanced-reward-v2` 或其 heldout 行为解释为视觉表征驱动的学习或决策差异。

### 1.2 可以保留

- MaleCNS v1.0 完整 retained graph 的导入、哈希和拓扑审计。
- 在固定版本、固定平台和固定初态下的确定性数值复现。
- 感觉代理、神经传播、塑性、固定解码和执行限制的分层架构。
- KC→MBON 权重更新、PAM11/PPL101 工程化输入等局部机制的**孤立测试能力**，但不得声称已形成可用视觉学习或交易策略。
- 所有历史实验作为诊断证据和失败记录保留，不覆盖、不删除、不改写为成功。

### 1.3 唯一允许的继续方向

若用户仍希望继续研究，必须另立“全脑动力学模型 v2”项目阶段，而不是把它包装成 R1 的一个新旋钮。新阶段首先解决动力学声明、E/I 标定、细胞异质性、非尖峰细胞表达和下游可驱动性；在这些基础门槛通过前，不得回到市场训练。

## 4. 模型范围为何必须收缩

完整 connectome 提供连接约束，但没有自动提供可用的全脑动力学。当前实现还包含一组范围很大的工程假设：

- 大量非 KC 细胞共享统一 LIF 参数；细胞类型特异的适应、膜参数和噪声没有系统标定。
- 接触数乘统一比例得到权重幅度，递质符号是粗粒度代理；这不是受体级 E/I 生理模型。
- 感光细胞、lamina 和 APL 等现实中具有分级或非尖峰性质的单元被映射进统一尖峰传播框架。
- 当前不应期内到达的突触输入被丢弃；该语义尚未做独立反事实审计，但 R0c 已表明仅缩小 dt 不会消除现象。
- 500 ms/市场观察的时间压缩、RGB 图表、12 mV lamina bias 和饱和电流是显示代理，不是验证过的视觉生理。
- 固定交易解码是工程接口；即使神经计数改变，也不能自动解释为行情语义或策略学习。

这些假设共同决定全脑工作点。继续只调整感觉侧或 KC/APL 局部参数，会把全局动力学缺口转化为结果驱动调参，并不能建立可归因模型。

## 5. 已满足的停止条件

以下条件已经满足，故现有稳定化路线必须停止：

1. **感觉剂量响应失败**：C 在两个合成网格均为硬跃迁、非单调并有历史依赖。
2. **局部抑制不是充分修复**：B2 能压低 KC 峰值，却不能消除离散翻转，且使 MBON 静默。
3. **持续高活动跨 dt 保持**：三个 dt 下，已点燃 trial 的 `cb_intrinsic`/KC 持续比例均超过 96%。
4. **细 dt 相互接近**：0.05 与 0.025 ms 的风险率及群体率通过冻结收敛门槛，不能继续把问题推给单一粗时间步。
5. **历史生产解释失效**：现有证据不支持把训练或解码差异归因于行情视觉表征。
6. **继续局部调参将违反隔离原则**：R0/R0b/R0c 已暴露具体失败形态，继续用同一数据选择旋钮属于事后拟合。

## 7. 历史结果的降级规则

以下产物仍可作为软件与机制审计证据，但不得作为视觉学习或交易学习证据：

- `runs/wc006_purged_fly_training/20261004T-balanced-reward-v2/`
- 其 2024–2025 heldout 前向测试；
- 基于该 checkpoint 的动作、MBON、收益或突触变化总结。

允许保留的历史结论：代码确实运行、工程化 reinforcement 被注入指定细胞、部分候选权重按规则变化、账本和 paper execution 可审计。

必须撤回或加限定的解释：视觉行情导致了可区分 KC 表征、权重变化体现了有效信用分配、动作差异来自市场感知、收益差异代表 fly 学习。

## 8. 若重新立项，全脑动力学 v2 的最低准入条件

新项目不得复用“R1”名称来暗示只是小修。至少应满足：

1. **独立模型声明**：逐类说明哪些细胞使用尖峰、分级电位、适应、噪声和何种递质/受体代理。
2. **参数来源**：关键时间常数、rest、阈值、权重缩放和 E/I 比例来自独立文献或独立 calibration；不得用 R0/R0b/R0c 的结果反推。
3. **完整图约束**：不删节点、边或接触；任何有效权重/细胞模型变更显式标注，不宣称“原样保留生理”。
4. **数值资格**：在接触市场数据前完成 dt、事件队列和不应期语义审计。
5. **合成感觉资格**：预注册刺激集上同时证明确定性、非退化剂量响应、历史依赖受控和刺激身份可区分。
6. **通路资格**：KC 达到预先规定的稀疏范围时，MBON07/11 仍有非零且可区分的下游响应。
7. **持续状态门禁**：撤刺激后不能无条件保持与刺激无关的高活动工作点；若模型有持续态，必须有预先声明的生理机制和退出条件。
8. **隔离验证**：synthetic calibration、synthetic holdout、市场 calibration 和市场 holdout 严格分离。
9. **固定解码最后接入**：只有感觉与下游通路门禁通过后，才能测试孤立塑性；只有塑性门禁通过后，才能讨论纸面市场 replay。

任一基础门禁失败即停止，不增加第二个机制来救第一个机制，也不得通过读取 active-KC/CB/MBON 输出在线钳制网络。

## 9. 永久禁止的“修复”方式

- 删除或屏蔽造成问题的节点、边、细胞类型或连接。
- 脚本直接选择交易，再把结果伪装为神经输出。
- LLM 根据行情、收益或实验结果选择动作。
- 根据 active-KC、CB 或 MBON 输出在线调节输入、阈值、抑制或权重以命中目标区间。
- 同时调整多个机制族，再用最终收益挑选组合。
- 用风险护栏选择替代交易；护栏只能拒绝订单。
- 在当前失败过的 holdout、R0 网格或固定 seed 上继续寻优并宣称独立验证。
- 将工程化多巴胺称为痛苦、快乐、意识或已验证的生物强化学习。

## 11. 最终结论

当前系统仍是一个完整连接图约束下、可复现的工程化尖峰网络实验平台，但**不是一个已验证能区分视觉行情、形成稳定稀疏 KC 表征、驱动 MBON 并通过塑性学习交易的模型**。

R0c 的通过不是“模型通过”，而是“失败现象通过了当前 dt 稳定性审计”。因此正确动作不是继续微调，而是停止当前稳定化路线、收缩声明，并由用户决定是否另立全脑动力学 v2，或仅保留孤立机制研究。
