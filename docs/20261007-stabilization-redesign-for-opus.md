# Stonkfly 稳定化重设计：交给 Opus 的架构评审稿

状态：**仅设计评审；尚未授权实现或实验。**  S3 继续阻塞。

## 1. 不可改变的边界

- 保留完整 MaleCNS v1.0 图，不删节点、不删边，不把脚本交易伪装成神经输出。
- 市场观察、感觉代理、神经传播、可塑性、固定解码和执行限制继续分层。
- 不使用收益、动作或 low/high 标签选择参数；风险护栏只能拒单，不能替换交易。
- learning off、paper-only 进行机制验证。任何重设计先在与调参数据隔离的冻结 60 帧上评估。
- 结果只能称为工程化稳定性或 counterfactual sensitivity，不声称意识、痛苦、愉悦或已验证盈利学习。

## 2. 已确认的证据

### S2k

- KC→KC 权重置零没有消除双峰。
- APL→KC ×2 会压缩活动，×4 接近静默。
- 因此简单增强全局抑制不是安全修复，KC 递归也不是充分解释。

### S2l / S2m

- KC1 前 low/high 的直接输入非常接近。
- KC1 对齐后，APL 输入绝对量很大，但五个窗口的 high-low 差异均为 0。
- 区分信息主要出现在 visual_projection 的 W1/W2，以及少数 other_cb 的 W4；差异随窗口换向。
- 四个固定低态 KC 没有共同的大幅输入缺口。

### S2n（正式 60×4）

- C：low/intermediate/high = `43/0/17`。
- visual W1/W2 ×0.5：`43/2/15`，20/60 帧跨 C 状态类别。
- top20 other_cb W4 ×0.5：`49/0/11`，16/60 帧跨状态。
- BOTH：`34/2/24`，22/60 帧跨状态。
- 干预会同时造成 low→high 和 high→low；BOTH 明显非加性，active-KC 交互项范围 `-1441..2717`。

当前判断：网络位于高度敏感的非线性分界附近。已找到敏感窗口，但没有找到单调、可控的“过强输入”旋钮。继续逐 source 消融的信息收益很低。

正式产物：

- `runs/plasticity_diagnosis/S2m/20261006T-kc1-window-balance-v2/`
- `runs/plasticity_diagnosis/S2n/20261007T-windowed-causal-attenuation-v1/`

## 3. 重设计目标

目标不是直接提高收益，而是先得到可重复、非双峰、对小输入扰动不发生大规模状态翻转的 KC 表征，同时保留固定解码和完整连接图。

建议把后续阶段改名为 **R1 stability redesign**，不再继续 S2 字母诊断。R1 必须使用独立 calibration split 冻结参数，再在现有 60 帧 diagnostic holdout 上一次性判定。

最低验收维度应包括：

1. active-KC 分布不再集中于约 4 与约 1300 两端；
2. 小幅、预注册的输入扰动不再导致大量 low↔high 翻转；
3. 同输入确定性复现，完整图和持久权重保持不变；
4. 不以收益或动作表现作为选择标准；
5. 不通过直接钳制 active-KC 数量或按输出反馈调参来“做出”目标分布。

## 4. 候选稳定化位置

### A. 感觉代理后的固定分布归一化（优先候选）

在 sensory proxy 与 neural propagation 之间加入显式、固定的 divisive normalization。参数只由独立 calibration split 的感觉驱动统计确定，不使用 KC 状态标签或收益。完整神经图不变。

优点：作用发生在敏感的 visual W1/W2 之前；层次清楚、可审计。风险：可能抹去有意义的市场幅度信息，或只是把双峰移动到别处。

### B. KC 内在适应性的固定重标定

只调整 KC 已有 adaptation 的固定强度/时间常数，不添加按 active-KC 数量反馈的控制器，不改变图或权重。

优点：局部、图保真。风险：S2k 的 KC 递归消融未解决双峰，说明单靠后发适应可能太晚；也可能把系统推向普遍静默。

### C. APL 抑制的时序重标定

保留 APL→KC 边，只研究固定的传递时序或动力学时间常数；不再做结果驱动的倍数扫描。

优点：使用已识别回路。风险：S2m 显示 APL 首次输入约为 KC1 后 `+68` steps，且 ×2/×4 已显示窄安全区；选择性改变延迟也会引入新的模型假设。

### 暂不建议

- 动态读取 active-KC 数量并把它钳到目标区间；这会成为隐藏输出控制器。
- 继续扩大逐 source 消融列表。
- 同时调整感觉增益、APL、阈值和适应性；无法归因。
- 在这 60 帧上寻优后又用同一 60 帧宣称稳定。

## 5. 建议的最小 R1 顺序

1. 先由 Opus 选择机制位置并挑战验收标准。
2. 只实现一个机制族，优先考虑 A；使用独立 calibration split 冻结最多 1–2 个参数。
3. 做小规模 smoke，验证 observer-off 等价、权重不变和层次分离。
4. 在冻结的 60 帧上一次性运行；失败则回到设计评审，不在 holdout 上调参。
5. 只有稳定性门通过后，才讨论恢复 S3；仍不以盈利作为稳定性门槛。

## 7. Opus 审阅（2026-10-07）

已核对：S2k、S2k-J、S2m v2、S2n 正式产物均存在，gates 全为 true；S2m JSON SHA256 与 S2n 预注册所 pin 一致；S2n 四臂 low/intermediate/high 计数与 §2 一致。以下统计均为 Opus 对现有产物与 `data/` 的只读复算。

### 7.1 对 §2 的补充与更正

- **KC→KC 假设被否定**（Opus 此前假设）。A 臂 high 帧反而由 17 增至 25，并出现中间值（121–1273）；C↔A 有 22/60 帧换态。去掉兴奋也会翻态，说明是分界敏感，而非“兴奋过强”。
- **B2 的表述不完整。** B2 的高态并未“压缩到消失”：19 个高态帧为 107–267 KC（约 2.6–6.6%，KCg 7.2%、KCab 5.7%、KCa'b' 0%），恰好落在生物学常见稀疏区间；但低态仍是约 4 个 KC，双峰仍在，且 C→B2 有 24/60 帧换态。即 APL 增益改变的是高态幅度，不是开关本身。
- **低态是固定的 4 个 KCg（KCg-s1 L/R、KCg-d L/R），在 C 的全部 43 个低态帧中完全相同。** 低态在功能上等于“无刺激响应”，不是稀疏编码。
- **感觉输入在 low/high 间几乎相同。** S2c：像素均值 0.816–0.821，R1–R6/R8 电流 high/low 比 0.9994–0.9999，与 active-KC 的相关 |r|<0.11；分叉最早出现在 visual_projection。按 `visual.py` 的 `30·L/(0.02+L)`，在浅色背景 L≈0.8 处每个 R8 已接近饱和（≈29.3/30），只有暗线像素携带对比度。网络实际承受的是近乎恒定的大直流驱动加微小调制，被推到分界上，由微小差异随机落向一侧。“不支持简单像素饱和”的旧结论只对“等均值不同图案可分”成立；对逐感光细胞的对比度压缩并不成立，建议修正措辞。

### 7.2 关键论点：网络本身对任何输入都是阶跃式

S2i B 的均匀灰阶（无空间结构）：uniform40 → 2 KC，uniform80 → 1400 KC，平均 drive 仅从 0.896 升至 1.109（+24%）。这说明阶跃存在于网络，与市场图像内容无关。任何纯输入侧的归一化（方案 A）只能把工作点固定在阶跃某一侧，不能把阶跃变成渐变。因此若验收标准是“非双峰、稀疏、渐变”，**单靠 A 原则上可能不可达**。在选择机制前应先确认这一点。

### 7.3 建议在 R1 之前加 R0：标签无关的剂量–反应测定（便宜、可判别）

- 刺激：仅合成刺激，不用 60 帧、不用市场数据。(a) 均匀灰阶在 uniform40–80 之间细分（如 17 级等距，预先固定）；(b) 固定均值下的对比度阶梯。每级重复测定确定性。
- 臂：C、B2（已有的 APL×2，仅作诊断对照，不是候选生产值）。
- 指标：active-KC 数–驱动曲线；是否存在阶跃；阶跃宽度（KC 数从 1% 到 20% 所需 drive 跨度）；有无滞后（升序/降序各跑一遍，各从 clean checkpoint 起跑与连续跑两种）。
- 判读：
  - C 与 B2 都是硬阶跃（中间级 ≤1 个）→ 双稳态是网络动力学性质，A 不能单独解决，R1 必须针对动力学（B/C 或 §7.4 的替代），否则停；
  - B2 呈渐变而 C 是阶跃 → 抑制强度/形式是主要杠杆，A 只用于把工作点放进渐变区；
  - C 本身在细分后呈渐变 → 问题在输入工作点，A（见下）优先。
- 这一步不触碰 holdout，可同时作为 calibration 数据来源之一。

### 7.4 对 §6 六个问题的回答

1. **A/B/C 选择：先做 R0 再定。** 若 R0 指向输入侧，A 应具体化为**感光细胞光适应 / 对比度编码**：每个感光细胞代理的半饱和点跟随固定时间常数的平均亮度（Weber/Naka-Rushton 适应），而非对整帧做任意 divisive normalization。理由是：它有明确生物学依据，位于感觉代理层，不触碰图，且只有 1–2 个参数（适应时间常数、指数）。注意 S2i B2 扫的是固定半饱和点，已失败；适应性半饱和是不同机制，不能被 B2 结果直接否定，但也不能视为已获支持。B（KC 适应）证据最弱：S2h 显示 KC 点燃后爆发在数十 steps 内完成，200 ms 适应来不及。C 见第 4 点。
2. **数值门槛，事先由文献与 R0 定，不看 holdout：**
   - 稀疏度：每帧活跃 KC 在 1–20% 之间（约 40–813），20% 沿用既有预注册上限；文献中常见约 5–10%（Honegger 2011、Lin 2014），只作参考，不作门槛。
   - 非双峰：holdout 60 帧中 ≥50% 落在 1–20% 区间；≤10% 帧 ≤10 KC（即“固定 4 KCg”态）；≤10% 帧 >20%。
   - 平滑：R0 剂量–反应曲线中，1%→20% 至少跨越 3 个预设驱动等级。
   - 抗扰：S2n 式 0.5× 窗口衰减下，换态帧 <20%，与 S2n 自身 gate 相同但方向相反。
   - 不用 Jaccard 均值作门槛；报告完整分布。
3. **calibration split：**
   - 首选不同年份：`data/bear_market_2018*`（与 2021–2023 holdout 完全不重叠），或 2024 之前未进入 60 帧的期间。
   - 若必须用 2021–2023：每个 holdout 日期按图表回看窗口长度做双侧 embargo，因为相邻日期的图表共享大量像素，否则会泄漏。
   - calibration 只允许使用感觉层/KC 层的无标签统计；不得读取 reward/aversive/neutral 标签、动作或收益。
   - 在 calibration 上冻结参数后写入预注册并 pin SHA256，然后才允许触碰 holdout。
4. **APL 时序修改：图保留（节点、边、接触数不变），但属于模型声明变更，必须写进 `docs/model.md`。** 同理，S2k 的 APL×k 改的是边的有效权重，也不应称为“保留图”。另外需要指出：生物 APL 是非尖峰、分级、局部的抑制单元；当前把 2 个 APL 作为单室尖峰 LIF，它必须先放电才能抑制（S2m：KC1 后约 +68 steps），本身就是一个已知的建模错配。若 R0 指向动力学，比“改延迟”更有原则的替代是“APL 作为非尖峰分级抑制单元”（由 KC 输入的低通总和产生连续抑制电流，仍只经由已有 APL→KC 边）。这是一个机制族、一个声明，参数由 calibration 冻结。它比任意延迟更少随意性，但仍是模型假设，需单独预注册。
5. **必须停止的情形：**
   - R0 显示 C 与候选机制下均为硬阶跃；
   - 候选机制需要两个以上自由参数才能过门槛；
   - calibration 最优点落在参数网格边界；
   - 任何方案需要读取 active-KC 数量或输出来调节输入；
   - holdout 一次性运行失败（失败后回到设计评审，不在 holdout 上迭代）；
   - 等价性、权重 hash、observer-off gate 任一失败；
   - 通过后 MBON07/11 全部静默（表征稳定但下游断开，同样不能进入 S3）。
6. **暂不排除 B/C，也不立即只预注册 A。** 先预注册 R0（单次、合成、无标签），再据其判读规则选定唯一一个机制族进入 R1。B 可以基本排除；C 若入选，应采用第 4 点的“分级 APL”形式，而不是延迟或倍数扫描。
