# wc006 v1 contract

wc006 is a paper-only multi-symbol experiment. One shared, unmodified
MaleCNS v1.0 `FlyController` receives exactly one deterministic composite RGB
observation per trade date. The original DNp20/DNpe017 decoder is unchanged.

The immutable manifest supplies the ordered OHLC universe, a fixed base-target
subset, exact SHA-256 for every per-symbol OHLC file, and a pinned initial
cash/positions/lots state. A close on T creates an
intent; the intent can only fill at the next valid session open. A-share rules
are 100-share lots, T+1 sell availability, Decimal ledger truth, configured
fees/slippage, and intents-before-fill. A risk veto rejects the original
intent; it never chooses another symbol, redistributes cash, or manufactures a
replacement trade.

The manifest shape is:

```json
{
  "version": "wc006-v1",
  "symbols": ["000603.SZ", "002536.SZ", "001331.SZ", "001309.SZ", "002080.SZ", "002837.SZ"],
  "base_targets": {"000603.SZ": "0.25", "002536.SZ": "0.25", "001331.SZ": "0.25"},
  "ohlc": {
    "510300.SH": {"path": "510300.csv", "sha256": "..."},
    "159919.SZ": {"path": "159919.csv", "sha256": "..."}
  },
  "initial_state": {"cash": "...", "positions": {}, "lots": []}
}
```

For the frozen smoke bundle, `initial_state` may instead be derived only from
two hash-pinned `initial_state_source` files (`plan` and `execution`). Both
must contain identical `state_before`; an old v2/v3 `state.json` is not a
valid substitute. This prevents inventing starting inventory for exit-only
symbols.

The base arm is a repaired deterministic ledger/curve using the same pinned
initial state, prices, 100-share rounding, exposure limits, commission,
minimum commission, slippage, and sell stamp duty. Neural feedback is the
incremental return versus that base arm, with explicit drawdown and turnover
penalties, once per date.

The ledger stores deterministic intent IDs, idempotent observations, and a
hash-chained event table. `events.jsonl` is only a materialized audit view;
the SQLite chain is authoritative during resume. Unknown outcomes halt the
run. Legacy-inferred market state is always marked non-authoritative.

The external fixed mapping is `BUY -> 1.0` base-target multiplier,
`SELL -> 0.5`, and `HOLD -> DEFER` while retaining the previous multiplier.
The initial multiplier is 1.0. Decoder magnitude is ignored. Symbols outside
the manifest base target are forbidden.

`--strict-market-state` fails closed unless every row has official status,
upper-limit, and lower-limit evidence. Without it, the run is explicitly
marked `authoritative_trading_state=false`; that mode is not evidence of
official trading-state correctness.

Training and frozen runs use independent directories. Provenance binds the
manifest/data hashes, graph/checkpoint hashes, decoder version and learning
mode. A frozen run starts from an independently supplied checkpoint and must
verify unchanged plastic-weight hashes; neural state may still advance.

The first implementation pass is test-only. No market replay, backtest, or
return inspection is part of this contract.
