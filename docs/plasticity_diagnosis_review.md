# 对 `plasticity_diagnosis_for_opus.md` 的审阅与下一步任务

审阅对象：`docs/plasticity_diagnosis_for_opus.md`
对照代码：`stonkfly/neural/rule.py`、`circuit.py`、`brain.py`、`controller.py`、`config.py`、`cli.py`
状态：本文档只给出审阅意见和诊断任务，**不修改代码，也没有运行任何实验**。下文标注为“假设”的内容都需要用数据核实。

## 0. 结论先行

1. 原文档的核心发现是 MBON 几乎沉默，Alpha 来自 selector。这一点很重要。如果核实成立，那么 `purged_experiments_summary.md` 里所有 “MBON Fly 收益/Alpha” 都要重新标注为 selector 加执行层的结果，不能再称为神经输出（AGENTS.md：不得把非神经结果当作神经输出展示）。
2. 原文档的根因分析有几处与代码不符（见第 1 节），4 个修改方案都不建议直接实施（见第 2 节）。
3. 下一步**先诊断、暂不改规则**（见第 3 节）。只有诊断结果指向可塑性规则本身时，才进入规则修改，并且要先登记评估标准（见第 4 节）。

## 1. 原文档分析中的问题

### 1.1 方案 B（按通路拆分 u/w）与现状数学等价

`rule.py:47-59` 的所有运算都是逐条边独立的（逐元素乘法和指数衰减），边与边之间没有耦合。`circuit.py:32-45` 构建的 `gain` 已经把 PAM11 只路由到 KC→MBON07 的边，把 PPL101 只路由到 KC→MBON11 的边。因此 u/w 存成一个扁平数组还是拆成两个数组，结果完全一样。原文档第 52-58 行说“共用数组导致同向变化”，这个说法不成立。

### 1.2 u 与 w 的相关系数为 1.0 是预期行为

w 是 u 经过 `weight_filter_seconds=0.05` 低通滤波后的结果，两者本来就应该几乎相同。这不是 bug，也不能作为“缺少独立信号”的证据。

### 1.3 规则本身有方向性，单向压低更可能来自奖惩投递时序

`drive ∝ kc_hz · dan_trace − dan_hz · kc_trace`：
- KC 先放电、DAN 后放电：第二项占主导，连接被削弱；
- DAN 先放电、KC 后放电：第一项占主导，连接被增强。

查看 `controller.py:220-245`：每次 observation 模拟 `neural_ms`（默认 500 ms），奖惩脉冲放在开头的 `pulse_ms`（默认 200 ms）。KC trace 的时间常数是 1 s，跨 observation 不会清零，所以脉冲开始时，KC trace 里还留着上一张图带来的活动。**假设**：这种时序让绝大多数更新落在“KC 先、DAN 后”的削弱一侧，这与原文档中只有 1.6% 的边被增强一致。需要用数据核实（见任务 T4）。

### 1.4 读出方向可能与生物学方向相反（需要查文献）

在常见的蘑菇体模型里，某个小区的多巴胺会削弱同一小区 KC→MBON 的输出。习得的趋近行为来自“削弱促进回避的 MBON”，反之亦然。现在的设定是：
- 奖励（PAM11）削弱 KC→MBON07；
- decoder 把 MBON07 当作“趋近 / 买入”（`controller.py:126-179`）。

照这样，奖励越多，买入倾向越弱。如果文献确认 MBON07 驱动回避或 MBON11 驱动趋近，问题就在固定解码层的方向映射，不应该通过修改可塑性规则来补偿。

**我对 MBON07(α1) 和 MBON11(γ1pedc) 各自的行为效价没有十足把握**，需要查原始文献核实（如 Aso et al. 2014 eLife 的 MBON 光遗传激活行为实验，以及后续工作），并在文档里写明引用。

### 1.5 衰减时间常数按模拟时间计算

`memory_decay_seconds=900` 指的是神经模拟里的秒数。每个 observation 只模拟 0.5 s，所以 1699 个 observation 加起来大约只有 850 s 模拟时间，不到一个衰减时间常数（如果每天不止一个 observation，需要按实际情况重算）。**假设**：权重被压低后基本恢复不回来，压低只会累积，最终导致 904 条边撞到下限。需要按实际的 observation 数量核算（见任务 T4）。

### 1.6 数字需要核对

- 训练天数：原文档写 1699 天，而 `purged_experiments_summary.md` 里的训练期是 609 天。要说明 1699 天是怎么来的（是否包含多轮训练，或包含其他时期）。
- 样本外 Alpha：原文档写 +53.69%，summary 写 +50.28%。要说明两者分别对应哪一次运行。

## 2. 对原文档 4 个方案的意见

| 方案 | 意见 |

| A 跨小区反号 | 没有解剖依据：PAM11 并不直接作用于 KC→MBON11 的突触，等于凭空加了一条通路。在没有文献支持之前不要实施 |

## 3. 下一步：诊断任务（暂不改规则）

执行要求：
- 全部使用 paper/回测模式，不下真实订单。
- 大规模数据运行交给 Luna subagent 执行，主 agent 负责审查产物。
- 每个任务的产物都放在 `runs/plasticity_diagnosis/<任务>/` 下，包括配置、manifest、所用 checkpoint 的 SHA256，以及代码版本（git commit）。
- 不根据这些任务的结果挑选参数。

### T1 空策略对照（确认 Alpha 来源）

在与 `runs/fly_purged_heldout_2024_2025/20260929T-mbon-thresh1_5-oos/` 完全相同的数据和执行设置下，跑两个对照：
- (a) Fly 的决策强制全部为 HOLD；
- (b) 完全不经过 Fly，直接执行 selector 的基线规则。

报告两个对照与原运行的收益、回撤和交易次数。如果三者接近，就确认 Alpha 与神经网络无关。之后需要在 summary 文档里把相关数字重新标注为“selector + 执行层”。

### T2 未训练与已训练大脑的放电对比

在相同的输入序列上（取训练期的一段，例如 2021 年前 60 个交易日，不使用样本外数据）比较：
- 未训练的大脑（`memory_w = 0`）；
- 训练后的 checkpoint（写明路径和 SHA256）。

每个 observation 记录：KC 放电总数、PAM11/PPL101 的发放率、MBON07/MBON11 各自的发放率、decoder 的原始输出。

判断方法：
- 未训练的大脑也几乎沉默：问题出在基线驱动、视觉输入或 tonic 电流，与可塑性无关，**改规则是方向错了**；
- 未训练时活跃、训练后沉默：可塑性压低造成了沉默，再进入第 1.3 和 1.5 节的分析。

### T3 读出方向的文献核实（不需要跑数据）

查清 MBON07(α1) 和 MBON11(γ1pedc) 各自的行为效价，以及 PAM11 和 PPL101 的强化效价。把结论、引用和不确定性写进 `docs/`。如果当前 decoder 的方向映射与文献矛盾，提出修正方案，但只作为提议，不直接改代码。

### T4 时序与衰减的定量核算

从现有训练运行的日志或 checkpoint 中统计：
- 每个交易日的 observation 数量和总模拟时长，以及整个训练期累计的模拟时长与 `memory_decay_seconds` 的比值；
- 一次脉冲期间 drive 两项（`kc_hz·dan_trace` 与 `dan_hz·kc_trace`）的相对大小，可以只抽样少量 observation 来记录；
- `memory_w` 分 MBON07 边和 MBON11 边分别统计的分布（原文档只给了合并后的统计）。

## 4. 进入规则修改前的门槛

只有 T2 显示“未训练时活跃、训练后沉默”，并且 T3 和 T4 指向规则或时序问题时，才考虑修改。修改前要先在文档里登记：
1. 修改的生物学依据和引用（只修改 rule 中的时序、衰减等机制参数，或修正有文献依据的读出方向，不能凭空添加通路）；
2. 评估标准，只在训练期数据或合成的奖惩配对测试上检验，例如：给固定图像配对奖励后，对应 MBON 的响应能按文献方向变化；
3. 冻结配置后，样本外数据只跑一次，结果无论好坏都如实记录。

仍然有效的约束：保留完整的 MaleCNS v1.0 图；可塑性只作用于已有的 KC→MBON07/11 边；权重有界；风控只能拒绝订单，不能替换交易；损益强化是工程化输入，不声称模型能感受疼痛或愉悦，也不声称已验证能盈利学习。
