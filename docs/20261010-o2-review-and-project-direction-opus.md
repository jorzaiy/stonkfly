## 2. O2 结果（描述性）

`dt=0.1 ms`、第一次重复下，8 个 PN × 6 个剂量的分类只有两种：

- **沉寂**：前 50 ms 内 KC 发放节点数为 0；
- **失控**：前 50 ms 约 2,850–3,200 个 KC 发放（约占 4,064 个的 70–79%），全脑约 66 万次发放，最后 500 ms 仍有约 33 万次，无法退出。

**没有任何一个 PN/剂量组合落在 `stable_nonzero` 区间。**

失控与 PN 直连 KC 的边数无关：

| PN | 原始出边 L1 | 直连 KC 边数 | 首次失控剂量 |
|---|---:|---:|---|
| DL1_adPN | 1,965 | 177 | 4096 仍沉寂 |
| M_lPNm11C | 340 | 1 | 2048 |
| M_lPNm11D | 479 | 7 | 1024 |
| DM4_adPN | 4,484 | 302 | 4096 |

所以失控不是 PN→KC 直接驱动造成的，而是 MB 以外的全脑循环网络先被引燃，再把 KC 卷入。这与 R0b 的吸收上态是同一类现象。

## 3. 跨阶段结论

| 入口 / 传递语义 | 阶段 | 结果 |
|---|---|---|
| 视觉，spiking | R0b | 随机进入吸收上态，与刺激无关 |
| 视觉，单侧 graded release | C0 v3 | KC 完全沉寂 |
| 视觉，双向 graded release | Q2 v2 | lamina 负反馈环振荡失稳 |
| 嗅觉 PN，单个原图事件 | O1 | 7 个沉寂，1 个（DM4）失控 |
| 嗅觉 PN，归一化剂量 | O2 | 只有沉寂或失控，没有中间区间 |

**根本问题不在感觉入口，而在"完整 MaleCNS v1.0 图 + 通用 LIF/电流型突触 + 统一 contact×0.275 权重缩放"这套动力学本身。** 它没有一个稳定、稀疏、依刺激而变的工作区间，而任何学习都必须建立在这样的区间上。更换感觉入口不能修复这一点。

这只是对本项目工程模型的结论，不是关于真实果蝇神经生理的结论。

## 4. 对"果蝇能否学会炒股"的判断

### 4.1 当前模型：不能

KC 表征要么全零，要么 70–79% 同时激活，且与输入内容无关。在这样的表征上，可塑性无法学到任何关于市场的信息。

因此，此前生产训练（例如 `20261004T-balanced-reward-v2`）中出现的任何决策或盈亏差异，都**不能**归因于"果蝇学到了市场规律"，只能视为模型状态噪声、执行规则或行情本身的结果。

### 4.2 即使换成能工作的模型，成功的可能性也很低

1. **计算能力上限低。** 果蝇蘑菇体在计算上大致相当于"稀疏随机扩展 + 奖励调制的线性读出"。在相同市场特征上，它的上限不会超过逻辑回归这一类简单模型。
2. **市场可预测成分极小。** A 股日频/日内的可预测信号很弱，扣除手续费和印花税后，绝大多数简单策略为负收益。
3. **奖励信号不匹配。** 三因子学习适合"刺激→几秒内的强奖惩"。盈亏奖励噪声大、延迟长、非平稳，不符合这一前提。
4. **归因困难。** 即使某段回测或模拟盘盈利，在没有稳定击败同特征简单基线之前，也更可能是噪声或行情所致，不能称为"学会了"。

## 5. 项目方向建议

1. **以完整的否定结果收尾。** 当前路线的价值在于：用一系列预注册审计记录了"完整连接组 + 通用 LIF 不能直接作为感觉-学习系统使用"，以及每一步的具体失败机制（吸收上态、单侧截断沉寂、lamina 振荡失稳、全脑引燃）。建议整理成一份总结文档，归档所有正式产物与哈希。
2. **不以"赚钱"为理由开新模型路线。** 若目标是收益，果蝇模型没有任何优势，直接做常规量化基线更诚实、更便宜。
3. **若出于科研或展示目的另开新项目**，必须先由用户在章程层面决定：
   - 是否放弃"保留完整 MaleCNS 图、不剪枝"的规则（例如只建 PN→KC→APL→MBON/DAN 的蘑菇体模型）；
   - 新 neuron/synapse 模型的参数从哪里来。只能来自外部生物数据，不能由"能稳定"、KC 输出或收益来选，否则就是训练一个"形状像果蝇的 RNN"。

   并事先写死三项门禁：
   - **表征门**：无市场数据的合成刺激下，KC 稀疏度在生物学合理范围（约 5–10%），刺激特异、跨 dt 一致、可退出；
   - **基线门**：接入市场后，样本外必须显著优于同特征的逻辑回归、随机策略和买入持有；
   - **预算与停止规则**：限定阶段数，任一门失败即停止，不追加机制。
4. 在任何新项目立项之前，sensory adapter、plasticity、S3、paper-market 训练和所有真实执行继续阻塞。
