# Stonkfly v2 蘑菇体实验汇总

日期：2026-10-12 UTC
状态：**阶段性归档；所有正式 NO-GO 判定保持不变**

## 1. 范围与解释边界

Stonkfly v2 以 MaleCNS v1.0 的右侧蘑菇体 PN→KC→APL→MBON/DAN 连接为结构基础，研究合成气味表征和工程化气味—奖励关联。实验没有接入行情、交易策略、纸面或真实执行，也没有把脚本行为包装成神经输出。

真实连接组只决定可用细胞、边和 aggregate contact 权重。连续 rate 动力学、全局/局部 APL 代理、合成气味、人工 DAN 脉冲、可塑性学习率、归一化 MBON score 和零阈值选择器均为工程假设。因此结果最多支持当前组合模型中的工程机制，不验证真实果蝇行为、痛苦/愉悦、意识或盈利学习。

MaleCNS v1 历史归档未被修改。旧 M1-RT/M2 域没有解封；后续探索使用新 seed 域。

## 2. 实验过程

| 阶段 | 研究问题 | 规模与对照 | 冻结结果 |
|---|---|---|---|
| M1-RQ freeze-v5 | 合成气味能否形成稀疏、稳定、可区分、可恢复且跨 dt 一致的 KC 表征；真实 B 拓扑是否优于度保持随机 C | 40 个拓扑（1 B + 39 C）、16 气味×10 trials、3 个 dt，另有 ZERO 与 APL-off | `M1_REPRESENTATION_NO_GO` |
| M1-E1 | 全局平均 APL 是否掩盖局部反馈抑制功能 | 全局 G、连接/亚型约束局部 L、APL-off O；16 气味×10 trials×3 dt | `E1_COMPLETED_EXPLORATORY`；L 相对 G 无实质改善 |
| M2-E | 固定 E1-G 感觉层和 KC→MBON 头能否 acquisition、reversal、retention | 8 对新气味；paired、frozen、shuffled、unpaired、DAN-omitted | `ENGINEERED_ASSOCIATIVE_UPDATE_NOT_OBSERVED` |
| M2-B | 连续 MBON score 能否形成固定零阈值的虚拟二选一偏好 | 4 对新气味；每阶段 10 probes；五臂对照 | `ENGINEERED_VIRTUAL_PREFERENCE_DIRECTION_UPDATE_NOT_OBSERVED` |
| M2-C | 固定模型的 10-probe 均值能否提高读出可靠性 | 4 对独立新气味；单次读出为对照；五臂不变 | `ENGINEERED_AGGREGATE_PREFERENCE_DIRECTION_UPDATE_NOT_OBSERVED` |

完整设计、冻结与诊断见同目录各 `STONKFLY_V2_*.md`。可公开复核的关键数值位于 [`docs/results/stonkfly_v2/`](results/stonkfly_v2/README.md)。

## 3. 主要数据与结论

### 3.1 M1-RQ：表征稳定，但资格失败

在科学 dt=0.025 ms 下：

- S1 稀疏度失败：1,907 个可驱动 KC 的 odor-level median 总中位数为 6.922%，但 odor 16 为 10.121%，超过逐 odor 10% 上限；使用全部 2,045 KC 时该值为 9.438%，但该描述性分母不能改变预注册判定。
- S2 稳定性/特异性通过：median reliability 0.9158，16/16 气味均不低于 0.5，分离统计量 `T_sep=0.8257`，固定检验 `p=0.0001`。
- S3 恢复通过：最大 tail active fraction 为 0，最大 state error 约 `5.36e-11`。
- S4 APL-off 失败：16/16 气味方向一致，精确符号检验 `p=1.526e-5`，但中位稀疏度增量仅 0.003671，低于冻结的 0.02 实际效应门槛。
- S5 B vs C 失败：`T_B-median(T_C)=-0.003751`，检验 `p=0.625`；没有证据表明真实 B 拓扑优于 39 个固定度随机 C。
- 三个 dt 的 gate 向量均为 `[false, true, true, false, false]`，跨 dt 数值检查通过。

这支持“该代理模型产生稳定、可分、可恢复的工程表征”，但不支持 M1 资格通过、足够强的 APL 稀疏化效应或真实拓扑优势。

### 3.2 M1-E1：局部 APL 代理没有带来实质改善

参考 dt=0.025 ms，L−G 的 mean-rate 平均差为 `-0.0001401`，odor-resampling 95% 区间 `[-0.0002282, -0.00007185]`；效应虽方向稳定但量级极小。相较之下，APL-off 与全局 G 的 O−G 平均差为 `+0.002150`，95% 区间 `[0.001463, 0.002945]`。G/L/O 的跨 dt 最大 NRMSE 分别约 `2.13e-4 / 2.13e-4 / 2.28e-4`。

因此，在只有 neuron-pair contact 总数、没有突触空间坐标与 APL cable 参数的“亚型完全区室化”代理下，局部模型没有显示有实际意义的改进。该结果不否定真实 APL 的空间局部性，只说明当前可实现代理不足以产生明显功能差异。

### 3.3 M2-E：存在稳定的双向更新，但未达到反转终点标准

- acquisition 变化均值 `+0.011776`，bootstrap 95% CI `[+0.010348, +0.013181]`；8/8 为正。
- reversal 变化均值 `-0.013861`，95% CI `[-0.015789, -0.012183]`；8/8 为负。
- P2 仅 6/8 气味对跨过零，低于冻结的 7/8；两对仍为 `+0.000579`、`+0.001522`。
- retention 同号 8/8，中位 retention ratio 0.9396。

所以配对差分显示可重复的工程化更新，但冻结的绝对终点没有通过，正式 NO-GO 保持不变。

### 3.4 M2-B：单次零阈值选择受 jitter 与偏置支配

四对气味均未同时满足 P1 为正、P2 为负、P3 保持负向，方向更新计数为 0/4。尽管如此，paired 相对 frozen 的 acquisition 差中差均值为 `+0.010574`，95% CI `[+0.009185, +0.011596]`；reversal 差中差为 `-0.013755`，95% CI `[-0.016831, -0.010678]`。

离线诊断显示单次 probe 的固定权重 pooled SD 为 0.026–0.054，系统性 normalized 初始偏置为 `-0.0191` 至 `+0.0160`。学习差分可重复，但绝对 score 是否跨零不可靠。

### 3.5 M2-C：10 次平均降噪，但不能消除固定偏置

旧 M2-B probe 的离线重采样显示，paired 方差从单次的 0.001627 降到 10 次均值的 0.000163；平均方向一致性从 70.8% 升到 85.2%，但最差 cell 仍仅 56.3%。

独立 M2-C 验证中，10-probe 均值的方向更新计数仍为 0/4。paired 相对 frozen 的 acquisition 差中差均值为 `+0.013412`，95% CI `[+0.011712, +0.016224]`；reversal 差中差为 `-0.014369`，95% CI `[-0.015956, -0.012532]`。聚合降低独立刺激 jitter，但不能移除 calibration 分母误差或结构性初始偏置，也不会放大学习效应本身。

## 4. 总结

v2 最稳健的发现是：固定感觉模型与人工 DAN/可塑性头组合后，paired 臂能产生方向正确、跨气味对一致的 acquisition 和 reversal **连续差分更新**。最稳健的反证是：这些更新尚不足以在独立气味上可靠控制固定零阈值的绝对二选一读出；增加观察次数只改善方差，不能修复固定偏置。

因此，截至本归档：

- M1-RQ、M2-E、M2-B、M2-C 的原始 NO-GO 全部保留；
- E1 没有为局部 APL 代理提供实质改善证据；
- 可以称为“当前简化模型中可重复的工程化关联更新信号”；
- 不可称为真实果蝇行为、已验证生物学习规则、连接组优势或交易能力。
